# Herramientas · Agencia Chalco

Tres utilidades web de un solo archivo. Corren completamente en el navegador: no hay servidor ni base de datos, y los archivos que cargas nunca salen de tu equipo.

**Portada:** https://jesus-trapala.github.io/reportes-agencia-chalco/

| Herramienta | Qué hace | Link |
|---|---|---|
| Dashboard de ventas | Meta del mes, desempeño por asesor, participación, formas de pago y modelos | [Abrir](https://jesus-trapala.github.io/reportes-agencia-chalco/dashboard-ventas-chalco.html) |
| Concentrador de reportes | Checklist diario por turno, cumplimiento por asesor y seguimiento de prospectos | [Abrir](https://jesus-trapala.github.io/reportes-agencia-chalco/concentrador.html) |
| Comparador de semáforos | Compara dos cortes de inventario PEPS: cambios de color, traspasos y violaciones de antigüedad | [Abrir](https://jesus-trapala.github.io/reportes-agencia-chalco/comparador-semaforos.html) |

## Uso local

Descarga el `.html` que necesites y ábrelo con doble clic. No requiere instalación ni conexión a internet.

## Notas

- El concentrador guarda su información en el `localStorage` del navegador, así que los datos quedan en el equipo donde lo usas.
- Los comparadores y el dashboard leen archivos CSV que tú cargas en el momento; no almacenan nada.
